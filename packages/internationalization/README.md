# `@podyard/internationalization`

Internationalization (i18n) utilities and dictionaries for Podyard.

## Overview

- Source: `src/`
- Dictionaries: `dictionaries/`
- Translation config/assets: `languine.json`, `languine.lock`
- Used by web-facing apps for locale handling and translations

## Scripts

```bash
bun run translate  # run languine translation workflow
bun run typecheck  # tsc --noEmit
```

Internal workspace package (`private: true`).

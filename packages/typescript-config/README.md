# `@podyard/typescript-config`

Shared TypeScript configuration presets for the Podyard monorepo.

## Overview

- `base.json` — base compiler settings
- `nextjs.json` — Next.js app preset
- `react-library.json` — React/library preset

## Usage

Extend these configs from app/package `tsconfig.json` files (e.g. `@podyard/typescript-config/nextjs.json`).

# `@podyard/analytics`

Shared analytics utilities for Podyard apps.

## Overview

- Source: `src/`
- Provides client/server instrumentation, env keys, and provider/helpers for analytics integrations (e.g. PostHog/Vercel Analytics)
- Internal workspace package (`private: true`)

## Usage

Import from package exports/subpaths as needed by apps and packages (e.g. `@podyard/analytics/*`).

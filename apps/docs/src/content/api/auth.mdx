## `/api/auth/*`

[Better Auth](https://better-auth.com) is mounted at `/api/auth` on the Hono API. All standard Better Auth endpoints are available under this prefix, using the email + password provider and the Prisma (PostgreSQL) adapter.

### Configuration

| Setting | Value |
| --- | --- |
| Provider | `emailAndPassword` |
| Adapter | Prisma (PostgreSQL) |
| Session cache | cookie, `maxAge` 30 minutes |
| Trusted origins | `BETTER_AUTH_URL` |

Users carry an optional `stripeCustomerId` field linking them to their Stripe customer.

### Common endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/api/auth/sign-in/email` | Sign in with email + password |
| `POST` | `/api/auth/sign-up/email` | Create an account with email + password |
| `POST` | `/api/auth/sign-out` | Sign out the current session |
| `GET` | `/api/auth/get-session` | Get the current session |
| `GET` | `/api/auth/get-user` | Get the current user |
| `POST` | `/api/auth/update-user` | Update the current user |

See the [Better Auth API reference](https://www.better-auth.com/docs/api-routes) for the full set of routes.

### Example — sign in

```bash
curl -X POST http://localhost:3002/api/auth/sign-in/email \
  -H "Content-Type: application/json" \
  -d '{ "email": "you@example.com", "password": "secret" }'
```

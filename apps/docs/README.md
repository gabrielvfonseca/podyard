# `apps/docs`

Podyard documentation site (Next.js + Fumadocs).

## Overview

- Source: `src/`
- Content/config: Fumadocs MDX/UI based docs app
- Port: `3004` (dev)

## Scripts

```bash
bun run dev        # Next.js dev server (port 3004)
bun run build      # Production build
bun run start      # Start production server
bun run typecheck  # tsc --noEmit
```
